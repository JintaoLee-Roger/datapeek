本文面向扩展维护者。公开读取器接口见[自定义读取器](custom-readers.zh-CN.md)。

## 执行模型

DataPeek 运行在工作区扩展宿主中。Remote SSH 下，Python 执行和文件读取发生在远端，Webview 在客户端显示。快速预览采用一次性 Python 请求，每个详细查看标签拥有独立的常驻读取进程。

| 模块 | 职责 |
| --- | --- |
| `src/extension.ts` | 解释器选择、发现、快速请求、产物校验和显示 |
| `src/autoPreview.ts` | 临时文件关联及恢复 |
| `src/details.ts` | 详细请求、进程生命周期、3D 标签和地址转发 |
| `media/detail.js` | Plotly 控件及显示状态 |
| `python/runner.py` | 脚本发现、执行和输出适配 |
| `python/detail_worker.py` | 常驻详细请求协议 |
| `python/datapeek/sources.py` | 通用数据源及读取器资源生命周期 |
| `python/datapeek/scientific.py` | 共用切片准备及 Matplotlib 绘图 |
| `python/datapeek/quick.py` / `quick.html` | 静态 Canvas 产物 |
| `python/datapeek/detail.py` | 切片/区域读取与 cigvis 服务 |
| `python/datapeek/colors.py` | 初始色阶和配色 |
| `python/datapeek/cache.py` | 持久预览缓存 |

## 读取器边界

核心负责通用数组格式，数据集专用字段、维度约定和预处理属于自定义脚本。数组读取器共享查看控件，Figure 绘图器负责自己的输出。上下文管理器读取器在会话结束前保持资源可用。

Python stdout/stderr 用于诊断。一次性请求使用响应文件，详细 worker 使用结构化消息协议。将本地文件暴露给 Webview 前，需要校验产物路径并限制输出体积。读取脚本仅在受信任的工作区执行。

## 显示与状态

快速预览准备所选切片、色阶及有限大小的显示缓冲，生成静态 Canvas HTML；自定义 Figure 走相应的图片/HTML 适配器。详细查看为明确选择的切片或区域请求采样数组。

缩放和平移只在前端执行，已应用色阶跨读取保持固定。前端保留概览供 Full View 恢复，读取失败保留原图。请求携带顺序信息，旧结果不能覆盖新选择。

切片和色阶状态按文件、读取器、dataset 和配置区分保存。面板关闭时清理临时产物；隐藏的详细标签保留读取器和显示状态。

## 缓存

持久预览缓存校验源元信息、参数、解释器/依赖版本和相关绘图代码。自定义读取器需显式启用；校验包含脚本同目录的 Python 文件，但不追踪外部依赖。

目录存储需遍历元信息，命中开销不是常数。缓存限制条数、字节数和存活时间，不完整或损坏的条目回退为重新生成。面板使用独立副本，淘汰缓存不会使当前图像失效。

详细查看另有完整切片的有界 LRU。区域请求裁取已缓存切片，未命中时向源提交区域索引；格式库自己的缓存和解压缓冲不在该 LRU 内。

## 3D 生命周期

详细 worker 调用 cigvis，从惰性数据源及选定位置、配色创建并显示切片。Viser 监听回环地址，`vscode.env.asExternalUri` 提供内嵌页面或手动浏览器入口使用的转发地址。

关闭 3D 标签会停止服务。关闭所属详细标签或返回快速预览，会终止读取器及相关服务。停止后重启可按新的二维参数重建，两个视图不持续同步。

## 自动预览

只读自定义编辑器处理已关联文件。临时开关修改用户文件关联，并限定工作区路径和协议，不写入数据目录。解析器匹配目标是 `scheme:path`，远端扩展宿主的 `file:` URI 需转换为界面的 `vscode-remote:`。

关闭或重载时恢复保存的关联，异常退出后在激活时恢复，并保留用户覆盖。目录仍按原方式展开。文件模式和排除容器通过配置定义，不在核心写入数据集规则。
