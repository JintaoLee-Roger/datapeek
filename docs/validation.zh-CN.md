## 兼容性边界

已测试 Python 3.12，声明最低版本为 3.10。测试使用已安装的科学计算依赖及支持惰性切片的 cigvis 版本。

完整 Remote SSH 桌面文件打开流程及最终 Webview 端口转发，仍需在真实 VS Code 窗口验收。浏览器和模拟宿主测试不能确认这些行为。Windows 进程清理和最低依赖版本组合尚未验证。

运行方式见[开发命令](implementation-plan.zh-CN.md)，计时条件见[性能方法](quick-preview-performance.zh-CN.md)。代码变化后应运行对应测试；仅修改文档时检查链接和内容，无需重复数据基准。
